# Mastery System — Agent Guidance

### Authoritative Rules

The authoritative game rules for Destroyed Faith are:

- `docs/Rules/Canonical/Players_Handbook.md`
- `docs/Rules/Canonical/Actives.md`
- `docs/Rules/Canonical/Active_Buffs.md`

These three documents are the Single Source of Truth for game mechanics.

Before implementing or changing any game mechanic, locate and verify its definition in the authoritative rulebooks.

Do not invent powers, power levels, stone abilities, artifact abilities, costs, effects, or mechanical exceptions.

If the rulebooks contain conflicting or incomplete definitions, report the conflict instead of creating a new rule.

Explicitly approved subsequent rule changes must be incorporated into the corresponding authoritative rulebook.
