# Contributing to Destroyed Faith / Mastery System

Thank you for your interest in Destroyed Faith.

The project owner retains exclusive control over the official Mastery System / Destroyed Faith Foundry core. Public source availability does not make the project open source and does not authorize community-maintained official distributions.

## Welcome without prior invitation

The following are welcome:

- bug reports;
- issue reports;
- feedback;
- design suggestions;
- clarification questions;
- discussion of play experience.

Submitting an issue or suggestion does **not** transfer ownership of unrelated material you may own elsewhere, and the project owner is not obligated to implement any suggestion.

No contributor may publish their own modified distribution of the system merely because they submitted feedback or a contribution.

## Code and content pull requests

Code, translation, data, or text pull requests should be submitted only after prior invitation or approval from the project owner.

Unsolicited pull requests may be closed without review.

## Invited contributions

If you are invited to contribute code, text, translation, data, or similar material to the official project, by submitting that contribution you confirm that:

1. you created the contribution or otherwise possess all rights necessary to submit it;
2. the contribution contains no third-party material under terms incompatible with proprietary integration into this project;
3. you grant the project owner an irrevocable, worldwide, royalty-free, transferable, and sublicensable right to use, reproduce, modify, adapt, distribute, publish, integrate, and commercially exploit the contribution as part of the official Destroyed Faith / Mastery System project;
4. you understand that the official project remains proprietary and source-available, not open source;
5. you retain any non-transferable moral rights provided by applicable law;
6. you will not assert that your contribution makes the project open source.

This is a contribution license grant for invited submissions. It is **not** a signed copyright assignment process and does not create an automated CLA workflow.
