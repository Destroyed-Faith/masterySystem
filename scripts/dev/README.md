# Developer utilities

One-off Foundry console macros and maintenance helpers that are **not** part of the player install.

| File | Purpose |
|---|---|
| `divine-clash-overlay-macro.js` | Optional Foundry macro snippet for Divine Clash overlay testing |
| `gate-console-noise.mjs` | One-shot helper that rewrites verbose `console.log`/`console.debug` under `src/` to gated `log.debug` |

These files are excluded from the release ZIP.
